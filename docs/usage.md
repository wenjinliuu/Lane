# Lane 使用指南

本文补充 README 中不适合放在项目首页的详细使用说明。Lane 不提供节点，也不会转换、
上传或收集用户的私人订阅。

## 保存为本地配置

完整配置包含策略组、DNS、规则引用和客户端兼容设置。首次导入后建议复制或保存为本地
配置，不要让远程完整配置自动覆盖已经填写的订阅地址和个人修改。

- Loon 重新导入时，应选择保留已有节点或订阅。
- Surge 托管配置需要先创建普通本地副本，再填写 `policy-path`。
- Quantumult X 的 `[server_remote]` 故意保持为空，订阅从 App 的节点资源页面添加。
- Shadowrocket 直接使用 App 内已有订阅，不在 Lane 配置中提供订阅模板。

## 添加多份订阅

| 客户端 | 第二份及更多订阅 |
| --- | --- |
| Stash | 取消 `Subscription2` 整块注释并填写 `url`；继续复制时使用不同名称 |
| Loon | 取消 `Subscription2 =` 的注释并填写；更多订阅复制该行并使用不同别名 |
| Surge | 启用隐藏的 `Subscription2`，并把 `我的节点` 改为引用 `Subscription1,Subscription2`；更多订阅继续加入引用列表 |
| Quantumult X | 在 `设置 → 节点 → 节点资源` 中继续添加 |
| Egern | 在 `我的节点 → urls` 下逐行追加 |
| Shadowrocket | 在 App 内继续添加 |

取消注释时要保留 YAML 缩进，不要把多个订阅地址拼进同一个 URL 字段。Surge 和 Egern
可能按节点名称去重，多份订阅尽量避免使用完全相同的节点名称。

## 策略组怎么选

- `我的节点`：查看并手动选择全部真实节点；QX 和 Shadowrocket 不显示此组。
- `Proxy`：默认代理入口，可选择全部节点或地区自动组；QX 中显示为 `代理选择`。
- `XX Auto`：自动选择该地区延迟较低的节点；Surge 对应名称为 `XX Auto Smart`。
- `XX Manual`：手动选择该地区节点。
- 服务组：默认跟随基础代理入口，也可单独选择 `DIRECT`、地区 Auto 或 Manual。

`Brokerage` 和 `Crypto` 只控制网络路径，不保证登录、入金或交易成功。Crypto 当前只包含
Binance、OKX、Bybit 和 Bitget；网络能够正常访问时，可以手动选择 `DIRECT`。

## 哪些内容会自动更新

| 内容 | 更新方式 | 是否需要更换主配置 |
| --- | --- | --- |
| 节点列表 | 客户端更新服务提供商订阅 | 否 |
| 域名与 IP 规则 | 客户端更新 Lane 远程规则 | 否 |
| 策略组、DNS、引用顺序和兼容性修复 | 下载新版完整配置 | 是 |

升级完整配置前请备份节点订阅和个人修改。升级后重新填入订阅地址；不要把含私人链接的
配置提交到公开仓库。

## 常见问题

### 地区组为空

先确认订阅内确实有对应地区节点，并检查节点名称是否包含地区国旗、中文全称、英文全称
或 US / JP / HK / TW / SG 代码。新加坡还接受 `狮` / `獅`。

### QX 为什么叫“代理选择”

Quantumult X 将 `proxy` 用作内置策略名。自定义组若再命名为 `Proxy` 会产生冲突，因此
Lane 在 QX 中使用 `代理选择`，功能与其他客户端的 `Proxy` 对应。

### QX 为什么没有“我的节点”

`代理选择` 已通过 `server-tag-regex=.+` 直接纳入全部真实节点，并同时保留五个地区 Auto，
再建立一个 `我的节点` 只会形成重复入口。

### 更新配置后订阅不见了

通常是远程完整配置覆盖了本地修改。恢复备份后，将完整配置保存为本地副本；日常只更新
节点订阅和远程规则。Stash 也可以使用 Override 单独添加私人 proxy provider。

### Surge 出现大量 HTTPS 或 TLS 失败

Lane 不配置 MitM。先检查 Surge 的“HTTP 捕获”是否开启；该设置独立于配置文件，切换
配置不会自动关闭它。

### 某个机场链接只有部分客户端能导入

不同客户端要求的订阅格式不同。若同一链接在其他正常配置中也无法导入，通常是服务端
返回格式、鉴权或响应内容与该客户端不兼容，并不代表 Lane 的分流规则有问题。
